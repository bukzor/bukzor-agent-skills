# The data holds a relation; the law needs a function

Ownership as written in the fleet is a relation -- one word,
several stipulators -- while the law's `owner` must be a function
to license anything. The double-stipulation census is that gap,
and it sorts three ways: sibling pairs, which only a person can
settle (CONTENTION); nested pairs, inert because the outer entry
owns (OUTERMOST_WINS); and foreign pairs, legal because namespaces
are per-ledger. Which of the three a corpus is carrying, and how
many, is what `--census` prints -- the shape of the gap is the
claim, and no count belongs in it.
