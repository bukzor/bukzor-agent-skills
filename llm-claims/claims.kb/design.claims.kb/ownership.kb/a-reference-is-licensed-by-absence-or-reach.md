# A reference is licensed by absence or reach

A reference is licensed when its name has no owner -- which for a
word is freedom and for a label is the dangling finding instead -- or
when the speaker's theory lies in the owner's reach. The owner is
resolved within one ledger's tree, never across the fleet: treating
ownership as a fleet-global function turned legal foreign doubles
into type errors, which is how the error was caught.
