# Every defect is an unlicensed name

Every defect this law recognizes is a reference gone wrong: a site
saying a name the law does not connect to a definition its reader can
stand on -- for the word sort, a use no owner licensed and someone is
answerable for; for the label sort, a citation resolving to nothing.
A ledger is a set of sites that name things, and the law has no other
subject matter.

The declined alternative was a defect taxonomy by mechanism -- stray
word, dead citation, contested stipulation -- but every entry reduced
to an unlicensed or unresolvable name, so the taxonomy was this claim
restated with extra kinds.
