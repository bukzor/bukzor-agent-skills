# Does A Backtick Still Exempt A Token?

What NON_CLAIM_TOKENS settles is the gate; still open is whether a
backticked span keeps any exemption from it once enumeration governs.

An answer would settle where the residual cost sits. Keeping the
exemption hides real cross-boundary mentions -- four today, two of
them this theory's own labels quoted unreachably from strata. Dropping
it sends true literals to the list -- shell variables, filenames,
callout syntax, five today -- which is more entries but one rule
fewer. Either is coherent; the census that would decide is small
enough to re-run at will.
