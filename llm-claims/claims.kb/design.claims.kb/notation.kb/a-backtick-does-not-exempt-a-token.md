# A Backtick Does Not Exempt A Token

A label-shaped token inside backticks is read like any other. Both
scans drop the exemption: the one asking whether a token names a
claim, and the one asking whether a theory says a word it does not
own.

NON_CLAIM_TOKENS had already retired the backtick as an oracle --
measured, fourteen of twenty-three backticked fleet labels were
ordinary mentions wearing decoration. Keeping it as a gate kept the
retired oracle doing the same work under another name, which is what
made this a fact rather than a choice.

Measured 2026-09-03, on the repaired scanners:

- The citation scan gains four hidden citations -- three claims in
  strata quoting `CLAIMS_ONLY` and `LEAST_FIX` from PRMS, with no
  import reaching either -- and its enumerated list grows from
  twenty-six tokens to forty-one.
- The ownership scan barely moves: one new finding fleet-wide, and it
  is a false positive, a directory name read as the word it contains.
  The scans hunt disjoint vocabularies, which is why. Citations are
  upper-case labels, which prose backticks freely; stipulations are
  ordinary English words, which it rarely does.

That false positive wants no new rule. Enumeration already governs it
(NON_CLAIM_TOKENS): one line on a list, visibly, once.
