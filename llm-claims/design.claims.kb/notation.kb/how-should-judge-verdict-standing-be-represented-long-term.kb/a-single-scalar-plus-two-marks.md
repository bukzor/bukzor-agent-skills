# A Single Scalar Plus One Open-Vocabulary Mark

What is shipped today: `standing: bare | open | agent | user`, plus
the additive `verdict:` field for a negative outcome. One assessor
only -- the sigil names whoever last ruled, nothing records a second
assessor's differing verdict. Verdict is the four-point chain plus
whatever word `verdict:` carries, never a value between them, never a
graded one. Cheapest to write and to read of every design here, and
the only one already live. Rejected as the long-term answer: this
fleet has already run the experiment of shipping a format that can't
hold disagreement or graded belief
(`../../purpose.kb/the-format-must-hold-whatever-is-actually-true.md`)
and watched it draw repeated motions to delete the field that proved
inadequate. Long-term, obviously insufficient.
