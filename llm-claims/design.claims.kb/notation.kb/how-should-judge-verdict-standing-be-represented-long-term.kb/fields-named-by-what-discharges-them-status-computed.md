# Fields Named by What Discharges Them, Status Computed

PRMS's shape (`prototype.personal-reasoning-management/corpus/demo.prms.kb/`):
`stmt:`/`proof:`/`premises:`/`authority:`, no standing field at all.
Status (described/framed/proven/stipulated) is computed from which
fields are populated, and a claim's trust base propagates through
`premises:` -- a claim can be proven *conditional on* another claim's
unproven stipulation, a state TERSE and VERDICT_JUDGE have no room
for. One real assessor per stipulation (`authority:`), and the first
design here where the judge can genuinely be a proof rather than a
person. PRMS itself is flagged elsewhere as likely to evaporate as an
artifact -- the shape is the prior art, not the file format.
