# Agent Fiat Gets Its Own Sigil

The agent's signature is kept distinct from the user's: `+` spends a
glyph on a distinction `!` could have absorbed, because the sigil
signs the judge (the-sigil-signs-the-judge.md).

It survives ../stance.kb/prefer-fewer-distinctions.md:

- `?` asks the user for an answer; `+` asks for a veto, and silence
  is consent — the two want opposite responses.
- Folded into `!`, the ledger could no longer say which of its
  settled questions the user has actually seen — exactly the
  population an agent most needs to surface, since it is where it may
  have decided wrongly on someone else's subject.
- The pair is scannable in one pass, `grep -nE '[A-Z_][?+]'` — the
  concrete return on the extra glyph.

Declined: a `superseded` status — the same kind of proposal, failing
the test `+` survives. Last-wins already says it, and the only thing
the extra word buys is a second way to be inconsistent.
