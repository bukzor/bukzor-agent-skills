# The data holds a relation; the law needs a function

several stipulators -- while the law's `owner` must be a function
to license anything. The gap is the double-stipulation census:
observed 2026-08-20 with the docket cleared, 0 sibling pairs (the
contended cases a person must settle -- 13 at first scan, all
adjudicated), 6 nested pairs (inert under OUTERMOST_WINS), 47
