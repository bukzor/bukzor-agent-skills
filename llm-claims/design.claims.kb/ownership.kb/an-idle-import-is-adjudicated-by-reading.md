# An idle import is adjudicated by reading

An import whose taker never says the taken words (LIVE, read across
the arrow) cannot be ruled on mechanically: under the fused `why:`
it may still carry real support, and only reading the citing theory
tells. So the scan files idle imports as an adjudication queue,
never as errors -- each entry resolves by reading into "keep, the
support is real" or "cull, the arrow is dead under both lenses."
