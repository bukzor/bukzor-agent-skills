# The Format Must Hold Whatever Is Actually True

"It's inflexible if we can't represent what's a matter of fact."
Consequence of `forced-misrepresentation-is-the-failure-mode.md`: the
world outruns any finite hand-picked vocabulary -- more than one
party can judge a claim differently, and a verdict can be finer than
a small discrete set -- so a format fixed to fewer shapes than the
world has is not merely limited, it is committed to misrepresenting
whatever falls outside its shapes, the day that happens.

Not hypothetical: this fleet has run this exact experiment twice.
`llm-discourse-graph`'s `likelihood` field has drawn repeated motions
to delete it, because a single scalar cannot honestly hold
disagreement or graded belief and users notice. `TRICHOTOMY.md`
itself is scoped to "both parties" -- a two-assessor world, not the
unbounded one `docs/dev/strata.claims.kb/purpose.kb/the-corpus-outgrows-any-reader.md`
already rules this ecosystem must survive. Both are the same failure,
found independently, twice: agreed that a design adequate only for
one assessor and a fixed few verdicts will need to widen, not later,
inevitably.
