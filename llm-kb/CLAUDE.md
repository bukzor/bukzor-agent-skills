# llm-kb

`claims.kb/design.claims.kb/` is a claim ledger in the file form,
`Skill(llm-claims-kb)`: one claim per file, `label:` and `standing:` in
frontmatter, `design.claims.md` the entry point. It holds what is
committed-but-contestable and what is still open about the kb pattern
itself.

Its two neighbours divide the rest: `migrations.kb/` records a
transformation with a scope and a status; `SKILL.md` and `docs/dev/`
state the settled pattern to a reader who wants to use it.
