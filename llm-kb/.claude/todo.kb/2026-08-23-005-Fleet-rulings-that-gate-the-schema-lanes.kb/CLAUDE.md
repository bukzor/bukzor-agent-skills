# Fleet rulings that gate the schema lanes -- maintenance guide

One recommendation per ruling for
`../2026-08-23-005-Fleet-rulings-that-gate-the-schema-lanes.md`, in the
shape of
`../2026-08-21-000-ref-rollout-beyond-todo-ideas.kb/2026-08-21-001-layer-entry-canonical-recommendation.md`.

## What belongs here

One dated entry (`YYYY-MM-DD-NNN-slug.md`, chronological) per ruling: the
evidence re-derived from live files, the recommendation, and the case
against it named explicitly. Prose-only -- no frontmatter, no schema.
The user's verdict is appended to the same file once ruled.

## What does NOT belong

- The edit a verdict authorizes: it happens in the lane that needed it,
  never here, and never in any `*/jsonschema/`.
- Open-task bullets: never use `- [ ]` here -- these files sit under
  `todo.kb/` and the open-task inventory scans them for that marker.
