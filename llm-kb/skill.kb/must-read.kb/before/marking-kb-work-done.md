# Before Marking kb Work Done

You're about to commit, request review, or transition to a new task on
kb content you've created or edited. Run the quality-pass sweep before
drift hardens.

**Procedure: `../../procedures.kb/run-quality-passes.md`.**

The procedure enumerates passes by urgency tier; treat Tier 1
(blocking) as non-negotiable and Tier 2 as required-when-applicable.
