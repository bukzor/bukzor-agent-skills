# reference.kb -- maintenance guide

Docs a consumer loads on demand: the pattern's full explanation, schema
and splitting guidance, a worked example. `SKILL.md` links each from the
occasion that needs it; a trigger in `../must-read.kb/` may require one.

## What belongs here

- Depth `SKILL.md` would carry for every load but only some tasks need.
- One subject per file, named for the subject.

## What does NOT belong here

- Directives that fire at an occasion -> `../must-read.kb/`.
- Methods run to completion -> `../procedures.kb/`.
- Proactive checks -> `../quality-passes.kb/`.

## When to add

When `SKILL.md` grows a section only some tasks read: move it here and
leave a one-line link.
