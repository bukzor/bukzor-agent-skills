# Consider Multiple Structures

A run considers multiple candidate structures, and keeps conjecturing
while new candidates still change the picture. It then kills its own and
says what killed each.

The sufficiency test is that the picture stops moving -- a natural
stopping point, and cheap to feel. It replaces a fixed count, which
bought padding: a run told to produce five produces five, and the fifth
is filler written to satisfy the count.

The same reasoning retired the instruction to include one candidate that
risks being wrong. Named as a requirement, it is answered
performatively: an agent produces a reach-shaped candidate it has no
belief in and kills it in the next sentence.
