# The Basis Opens with a Layer 0

Delivery opens with a Layer 0: one sentence the whole basis reduces to,
plus the small number of named laws it refines into. This is a further
subtraction of the basis, not a second artifact -- the parent node of
what it summarizes, not a copy of it.

This is not `ONEPAGE` revived. `ONEPAGE` was a size budget on the
ledger itself, and stays rejected: the ledger's size should track what
the design has to say, not an arbitrary page limit. Layer 0 is narrower
and sits above the ledger rather than constraining it -- the historical
instance was one sentence ("authority belongs to acts; everything else
is a projection; a change is judged by what it forces to re-project")
plus three named laws, placed at the parent node of the thing it
summarized, stamped so it can go stale honestly rather than drift
silently in a second copy.

A poset-and-table entry point (`Skill(llm-claims-kb)`'s convention) is
not a substitute: it indexes the theories, at their own grain. Layer 0
compresses past theory-grain to one sentence nothing else needs. Where
a run has no true one-sentence reduction -- some designs don't -- say
so rather than force one; a forced Layer 0 is worse than none.
