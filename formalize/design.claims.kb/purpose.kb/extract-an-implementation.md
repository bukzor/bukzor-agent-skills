# Extract an Implementation

The basis is eventually meant to yield a known-good implementation,
extracted from a fully elaborated formal design.

Unbuilt, and the more distant of the two. Its live consequence is the
word *elaborated*: a basis that gestures at its structures leaves
nothing to extract from, so the run drives toward statements complete
enough that an implementation would follow.
