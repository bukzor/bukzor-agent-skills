# setting.kb -- maintenance guide

## What belongs here

Anything naming a proper noun: a skill, a file format, a tool, an
operator. If the claim would be restated wholesale by moving to another
suite or another owner, it belongs here.

## What does NOT belong here

A commitment that survives the move -> the theory whose vocabulary it
needs. The tell is a rewrite test: state the claim for a different
operator using different tools. If what survives is recognizably the
same claim, it was never a setting claim.
