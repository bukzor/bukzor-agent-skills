# Filing to Disk Is Optional

Filing the account to an on-disk `*.claims.kb/` is optional
post-processing.

This reverses the skill's original conception, which treated the
directory as the deliverable and the chat as a staging area. The
reversal follows from where the payoff is: FREE arrives when the basis
is in hand, and a run that has to reach a filing bar before it delivers
anything makes the cheap, frequent case expensive. `Skill(llm-claims-kb)`
takes the ledger to disk when the account earns keeping.
