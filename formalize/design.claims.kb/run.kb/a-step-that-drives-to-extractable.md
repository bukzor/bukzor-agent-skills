# A Step That Drives to Extractable

The procedure carries a step that elaborates the surviving structures
far enough that an implementation could be extracted from them.

The test is concrete: read a claim and ask what a program written from
it alone would do. A claim that leaves that underdetermined is
gesturing, and the gesture is where the design's real underspecification
hides -- which makes this step useful today, long before anything
extracts anything.
