# A Refuted Identification Is a Result

A refuted identification ships as a result: *this specific structure is
not here*, for the structures the run actually attempted.

Both qualifiers are load-bearing.

- **This specific structure.** What a failed law licenses is a verdict
  on the candidate that was tried. The design may still carry a
  structure nobody has proposed yet.
- **Actually attempted.** The report covers the run's own candidates,
  since it is the failed attempt that saves the next agent from
  repeating it.

A refutation earns its place the same way an identification does: by
what it saves. It stops one candidate from being re-conjectured, and it
often localizes the offending part of the design precisely.
