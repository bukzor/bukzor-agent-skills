# Standing Honesty

The sigil signs the judge, so the rot is a mark that misstates one.

- A `bare` claim must rest on something: a `verify:`/check note or
  `why:` premises. Bare with neither is a hidden judge --
  `grep -rL -e '^verify:' -e '^why:' --include='*.md'` the files
  whose `standing: bare`, then read the survivors.
- `agent` is a resting state: in force as written, veto invited,
  silence consent ([PROVISIONAL]). The agent-signed set
  (`grep -rl 'standing: agent'`) is where the owner looks to veto, not
  a queue that must empty. Surface one of its claims only at an
  occasion that makes a wrong call costly -- it is about to be built
  on, promoted, or published -- and then as a veto offer, not a
  request to sign.
- `standing: open` wants an answer, not tenure:
  `grep -rl 'standing: open'` and ask of each what could settle it.
