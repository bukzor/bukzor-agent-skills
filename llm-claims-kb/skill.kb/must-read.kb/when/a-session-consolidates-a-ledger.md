# When a session consolidates a ledger

> [!DRAFT] agent-authored 2026-11-25, vetoable

The session's job is to return a project to legible, not to add to it: a
consolidation session, a cleanup pass, or a review of a ledger as a whole. A
project that schedules these says so in its own policy. Here the ledger is
the work, not the place an edit lands.

Smooth each ledger the session touches: [smoothing]. It runs the sweep
before and after its walks, so the sweep needs no separate run.

## When NOT to trigger

- A feature session that edits a few claims: the per-edit and pre-commit
  entries cover it (`../after/editing-a-claims-kb.md`,
  `../before/committing-a-batch-of-claims.md`).
