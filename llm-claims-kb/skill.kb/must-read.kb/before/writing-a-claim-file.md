# Before Writing a Claim File

> [!DRAFT] agent-authored 2026-11-25, vetoable

How to write the body is `Skill(llm-claims)`'s
`skill.kb/must-read.kb/before/writing-a-claim.md`; read it first. The file
form adds the frontmatter, and three passes are due while you write it:

- `why:` -- a claim that follows from others cites them, and names the
  occasion that needs it written down: [corollaries].
- `standing:` -- the sigil names who judged; `bare` rests on a `why:` or a
  `verify:`: [standing-honesty].
- a quoted ruling -- every qualifier in the quote survives into the body:
  [ruling-fidelity].
