# Standing Honesty

The sigil signs the judge, so the rot is a mark that misstates one.

- A `bare` claim must rest on something: a `verify:`/check note or
  `why:` premises. Bare with neither is a hidden judge --
  `grep -rL -e '^verify:' -e '^why:' --include='*.md'` the files
  whose `standing: bare`, then read the survivors.
- The agent-signed set is the user's review queue, and it only ever
  grows until reviewed: `grep -rl 'standing: agent'`. Each entry is
  debt -- closed out by refactor, correction to bare, or a user
  ruling.
- `standing: open` wants an answer, not tenure:
  `grep -rl 'standing: open'` and ask of each what could settle it.
