# Survives Dumb Media and Dumb Tools

The notation survives hostile rendering and rewards the dumbest
consumer: labels are clean greppable prefixes (trailing sigils, so
`grep XY` finds every version and reference), one claim per line, no
glyphs a chat client mangles (smart-quoting eliminates `'` as a sigil).
Notation that needs a parser to read correctly will not be read
correctly.
