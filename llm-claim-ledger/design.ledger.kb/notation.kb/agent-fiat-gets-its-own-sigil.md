# Agent Fiat Gets Its Own Sigil

`+` is spent on a distinction `!` could have absorbed: the sigil signs
the judge (the-sigil-signs-the-judge.md), and the agent's signature is
kept distinct from the user's.

It survives ../stance.kb/prefer-the-smaller-ontology.md because the two
want opposite responses. `?` asks the user for an answer; `+` asks for a
veto, and silence is consent. Folded into `!`, the ledger could no
longer say which of its settled questions the user has actually seen —
and that is the population an agent most needs to surface, since it is
exactly where it may have decided wrongly on someone else's subject.

The pair is scannable in one pass, `grep -nE '[A-Z_][?+]'`, which is
the concrete return on the extra glyph.

A `superseded` status is the same proposal that fails the same test:
last-wins already says it, and the only thing the extra word buys is a
second way to be inconsistent.
