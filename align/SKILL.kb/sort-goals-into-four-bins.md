# Sort Extracted Goals into Four Bins

During Extract (procedure step 1), when the target embodies design
decisions, sort each extracted goal into exactly one bin:

1. **Rules** — filter the design space: work that violates one is
   non-conforming, whoever proposes it. State each as the filter it
   is, with the decision it actually filtered as evidence.
2. **Heuristics** — sort the design space: they prefer candidates
   without forbidding any, and deviating takes recorded
   justification.
3. **Short-term / tentative plan** — what is settled for now,
   binding nobody.
4. **Long-term / aspirational plan** — deferred structures and open
   questions, with what would release each.

A goal that straddles bins is more than one goal — split it. The
user is chiefly interested in rules, then heuristics; the plans
mostly serve as evidence for inferring the other two. Present rules
first and fullest.

Provenance: the 2026-08-17 census of the llm-claims verdict batch —
an unsorted extraction conflated the bins and cost a full round
trip. Probationary: the next /align run over a design target
discharges or defeats this procedure.
