# When the Target Embodies Design Decisions

The /align target is or contains design work — a design ledger, an
ADR, a schema, a plan choosing among alternatives — rather than
plain prose or inventory.

## Directive

Read and apply `../../sort-goals-into-four-bins.md` during the
Extract step: every extracted goal lands in exactly one of the four
bins, rules presented first.

## When NOT to trigger

- The target has no design-space content (an essay, a report, a
  todo inventory) — extract goals flat.
- The target is already a single bin (a pure backlog, a pure
  constitution) — say so rather than manufacturing empty bins.
