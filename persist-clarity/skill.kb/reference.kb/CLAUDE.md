# reference.kb -- maintenance guide

Docs a consumer loads on demand once the user elects to persist;
`SKILL.md` links each from the step that needs it.

## What belongs here

- The filing strategy for one ecosystem or concern, one file per
  subject.

## What does NOT belong here

- The operation's steps and its election rule -> `SKILL.md`.
- Why the operation is shaped this way -> an ADR in `../../../docs/dev/adr/`.

## When to add

When `SKILL.md` would otherwise carry a section read only after the
user says go.
