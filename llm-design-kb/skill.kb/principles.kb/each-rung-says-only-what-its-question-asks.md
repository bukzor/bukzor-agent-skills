# Each Rung Says Only What Its Question Asks

A claim answers its rung's question and leaves everything below it
underdefined. A mission says what problem and for whom, not what solving it
consists of; a goal states a stance, not the features that realize it; a
requirement states what must be true, not the format that makes it so. A detail
that answers a lower rung's question belongs on that rung. The test: could the
sentence change without the rung's question getting a different answer? Then it
is a lower rung's.

Before cutting such a detail, find where it lives below. If nowhere, move it
there rather than delete it ([ONE_HOME]).

`state-properties-not-mechanisms.md` is this lens's requirement-and-architecture
case. Extracted from my-own-shadertoy (`github.com/bukzor-sandbox/my-own-shadertoy`), session 59b55f01, 2026-11-23..25: a mission that defined understanding, and five goals
carrying architecture's vocabulary and the milestone ladder's feature list.
