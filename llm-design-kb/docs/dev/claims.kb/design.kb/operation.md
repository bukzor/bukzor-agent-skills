# operation -- the three beats

Writing a design record has three beats, taken from
`Skill(persist-clarity)`: **encode** it as a claim ledger in chat,
**review** it, **persist** it to disk. The beats are the same because
the problem is the same -- understanding that exists only in a session
has to become something a cold reader can argue with.

What this skill adds to the shape is the stratification (the ledger is
rendered rung by rung, and reviewed the same way) and tense.
