# Old Towers Stay Legal

A numbered tower keeps working, and no instance is required to move.
Modernization is per-instance and opportunistic: an agent already
working inside a tower converts what the work touched, and nobody goes
looking for conversions to do.

The route for whoever meets one is a single file --
`llm-design-kb/skill.kb/must-read.kb/when/meeting-a-numbered-design-kb-tower.md` --
which is both the trigger and the guide. Splitting those into two
files would have added a redirect and no information: the path already
names the occasion.

`jsonschema/layer-entry.jsonschema.yaml` stays on that warrant, and
stops being recommended. A record kept as a ledger binds
`skill://llm-claims-kb/jsonschema/claim.jsonschema.yaml` instead, and
the field the two share -- `why:` -- means the same thing in both,
this skill having been where the claim schema got it.
