# The Fourth Rung Is Architecture

The rung answering "how do we satisfy the requirements?" is
`architecture`, renamed from `design`.

The reason is the container: the record lives at
`docs/dev/claims.kb/design.md` beside `design.kb/`, so the old name
yields `design.kb/design.kb/` -- a name repeating the word its
container already supplies. That is the same redundancy that removed
the middle token from `claims.kb/design.claims.kb/`, applied one level
down.

"Architecture" is also the more honest name for what the rung holds:
the major abstractions and their relationships, which is a narrower
thing than "the design" -- the whole record is the design.

Legacy towers keep `040-design.kb/` untouched; the mapping is in
`llm-design-kb/skill.kb/must-read.kb/when/meeting-a-numbered-design-kb-tower.md`.
