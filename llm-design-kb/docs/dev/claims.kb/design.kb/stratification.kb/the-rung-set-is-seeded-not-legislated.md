# The Rung Set Is Seeded, Not Legislated

The default six rungs ship as the `ontology:` of the skeleton's
`design.md`, not as a table SKILL.md enforces. A project that needs a
different stratification revises its own defining claim, which is an
ordinary edit under ordinary governance and lands at the standing of
whoever ruled it.

This is what makes "all layers are optional" -- which the incumbent
asserted in a sentence with no mechanism behind it -- into something
with a mechanism: the rung set is a claim in the project's own record,
so dropping a rung is an act with an author, and adding one is
reviewable like any other claim.

SKILL.md still names the six, because an invoker needs them to act and
hot text that delegates its operative content to cold text charges the
invoker twice. Naming is not legislating: the body says these are the
default the skeleton seeds.
