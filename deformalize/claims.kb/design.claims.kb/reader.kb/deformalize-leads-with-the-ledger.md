# /deformalize Leads with the Ledger

The three output forms rank:

1. `Skill(llm-claims)` -- primary;
2. `Skill(llm-claims-kb)` -- secondary;
3. the plain-old-Python reification -- tertiary, and optional.

Python was the whole of `/deformalize` before this ruling, on the theory
that running code is where a formal account's slid-over seams surface.
It does surface them, and it costs a project home, a test suite and a
promotion step to do it. The glossary and the successor theories deliver
the reading the exercise was bought for at a fraction of that, so the
code becomes the escalation rather than the entry point.
