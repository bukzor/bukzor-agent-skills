# Unconditional needs inline; conditional needs as breadcrumbs

Everything a user of the skill unconditionally needs appears directly
in `SKILL.md`. A conditional need -- design motivation, the options
declined -- is a breadcrumb: a link that says when to follow it. Where
conditional needs grow many, a `must-read.kb/` systematizes them as
trigger-named files; for a one-off, a prose markdown link is enough.
