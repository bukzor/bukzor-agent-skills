# Restate each fact where it is read

Each file restates the facts its reader needs, so no reader follows a
link: the plan restates the design, a Final report restates its
unit's public API, and downstream briefs quote that report.

Superseded by ONE_HOME (`one-home.md`). Each copy is a second home,
and only the original is kept true: code stays true because its type
checker and tests hold it there, while a report's copy of its API,
and every brief that quoted it, drifts with the next change.
