# Give every fact one home, and link to it

Write each fact once, in the place a reader would trust, and replace
every other statement of it with a link.

It answers the cost that mattered: drift between copies, not the
volume of the record. A plan whose handoff files were as long as its
code still resumed cleanly from them, while each restated fact went
stale in at least one place.
