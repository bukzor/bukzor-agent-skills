# What a handoff file's text claims

A handoff file's `status:` is its tense: an open handoff file states
the current truth, and a done handoff file is a frozen record of what
its agent did.

- Open: an amendment is an in-place edit, and a mistake is deleted,
  not documented.
- Done: nobody updates it. A later correction is a new unit, or an
  edit to the fact's home.
