# Resume from the disk alone

After an interruption, the disk alone shows which units were in
flight, how far each got, and which of its edits were finished. A
fresh coordinator with no memory of the session can resume every unit.

Checked by resuming a plan in a new session from its files and its
git state, with no transcript.
