# subagent-handoffs -- technical policy

Rules that bind every file of this skill -- its manual, its templates,
and this ledger -- rather than describing any one of them. Each policy
claim carries `force:` (`must` / `should` / `may`, RFC 2119) and a
`why:` naming the goal it serves, where one does.
