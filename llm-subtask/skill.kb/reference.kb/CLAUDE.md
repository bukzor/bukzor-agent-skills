# reference.kb -- maintenance guide

Deep dives a consumer loads on demand; `SKILL.md` carries the working
summary and links each file here.

## What belongs here

- Explanation of a mechanism or pattern too long for `SKILL.md`.
- One subject per file, named for the subject.

## What does NOT belong here

- The working rules an agent needs on every load -> `SKILL.md`.
- Rationale for a decision -> `docs/adr/`.

## When to add

When a `SKILL.md` section is read by only some tasks: move it here and
leave a one-line link.
