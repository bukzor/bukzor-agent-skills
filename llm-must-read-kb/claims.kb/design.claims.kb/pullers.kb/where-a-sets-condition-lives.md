# Where Does a Set's Condition Live?

A set is a directory and has no frontmatter, so the grammar has nowhere
to put the decidable condition a mechanical puller needs. Candidates: a
descriptor file inside the set (`while/X/.trigger.yaml`), or admitting
`while/X.md` as the set's descriptor rather than a trigger body, which
amends the reserved-names claim. The judgment-protocol session's
concession-regex hook is an instance of what needs a home. An answer
settles which of those two the reserved-names clause keeps.
