# The Shell Loader Is the Mechanical Endpoint

The user's shell `intent.d` loader is the gradient's endpoint running
today: every guard runtime-decided, the noticing premise free on every
node. It exists because its conditions are shell-decidable predicates.
A bank's occasions are mostly judgment-shaped, so the endpoint is
reachable per occasion exactly as far as a decidable condition can be
written for it -- which is what `where-a-sets-condition-lives.md` asks.
