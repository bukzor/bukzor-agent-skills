# The Three Scopes Are Mechanically Pulled Sets

The skill's personal, project, and skill banks are sets over mechanical
occasions -- the project bank is the set at "cwd is in this repo", the
skill bank the set at "this skill is loaded" -- pulled by the runtime
rather than by the agent. Same construction as `while/`, different
puller.
