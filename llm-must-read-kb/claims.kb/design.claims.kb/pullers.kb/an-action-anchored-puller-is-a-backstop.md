# An Action-Anchored Puller Is a Backstop

A mechanical puller anchored to an action -- a hook on the Edit tool --
fires after planning, so for a set with `before/` members it installs
too late for the first action. It can replace the judgment puller only
where the set's members are `after/` or `when/`, or where the occasion
genuinely begins at an observable action; otherwise it runs under the
judgment puller as a backstop -- late for an approach-shaping body, in
time for style bodies. And it is the one intervention aimed at the
observed failure: the runtime asks "is this an occasion?" when the
agent's mode would not. Defense in depth is already the floor's rule,
so this costs nothing new.
