# Recency Improves Recall

The surviving argument for sharding at the end of the debate: a set
listed just-in-time sits later in context than a session-start listing
and is therefore recalled better. Conceded as plausible, then found
unsupported -- the only audit shows the dominant miss is mode or an
absent listing, neither of which moves with a trigger's position. Both
sides of the debate argued a variable the evidence does not implicate;
sharding's case now rests on cost and precision
(`../policy.kb/a-set-earns-its-place-on-cost-and-precision.md`).
