# Pullers -- who notices an occasion begin

Coins: a **puller** is whatever performs an install; it is
**mechanical** when a runtime event fires it with no agent judgment,
and it is **judgment** when it is the agent noticing.

The soundness theorem rests on one premise, that each occasion's begin
is noticed. This theory prices that premise per occasion, records what
the audits say about when noticing fails, and describes the gradient
from judgment to mechanism -- the subject `Skill(llm-triggers)` picks
up where this ledger folds into it.
