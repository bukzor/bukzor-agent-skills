# The Interval Juncture Is Spelled `while`

The bank's slugs are gerunds (`making-code-changes`), and "while" takes
a gerund where "during" wants a noun. "If", the word English reaches
for in "before going outside, if it's raining", is a rescue of the
wrong path order -- see `the-set-comes-first-in-the-path.md` -- and is
not needed once the set is outermost.
