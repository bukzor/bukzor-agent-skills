# The Set Comes First in the Path

A set's occasion is outermost and its members' junctures inside:
`while/X/before/Y`, never `before/Y/while/X`. Read aloud, the second
form puts the guard after the action -- "before going outside, while
it's raining" -- and English rescues it with "if"; the first form reads
as written -- "while it's raining, before going outside". The
awkwardness diagnosed the order, not the word.

The declined form, a set nested under a point juncture, also fails
structurally: a set may hold members of every juncture, and
`before/X/after/Y` is juncture under juncture.
