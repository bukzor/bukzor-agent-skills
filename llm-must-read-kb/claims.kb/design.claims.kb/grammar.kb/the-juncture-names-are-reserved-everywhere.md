# The Juncture Names Are Reserved Everywhere

The four juncture names are reserved at every namespace level. So
`before/git/while/` is malformed -- a namespace directory may not spell
a juncture, and a point cannot own an interval -- and `while/X.md` is
malformed, because `while/` holds sets and "read this while X" is
already `when/X.md`. A reserved name is a directory exactly because it
contains the open set: trigger files under a point juncture, sets under
`while/`.

`../pullers.kb/where-a-sets-condition-lives.md` may amend the
`while/X.md` clause if a set's descriptor needs a file of that name.
