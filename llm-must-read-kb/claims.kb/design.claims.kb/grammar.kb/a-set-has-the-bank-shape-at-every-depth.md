# A Set Has the Bank Shape at Every Depth

`bank := set` and `set := before/ after/ when/ while/`. Point junctures
hold trigger files under namespace directories; `while/` holds sets,
one per child directory. The rule recurses without limit and the bank
is the outermost set -- there is no root special case. Smallest
example: `while/making-code-changes/before/writing-python-code.md`,
and nested, `while/making-code-changes/while/debugging/when/stuck.md`.
