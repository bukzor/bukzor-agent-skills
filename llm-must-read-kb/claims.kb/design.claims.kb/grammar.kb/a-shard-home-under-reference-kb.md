# A Shard Home Under `reference.kb`

The opening proposal: move groups of triggers "off to the side", under
`reference.kb/`, with a higher-order trigger that lists the subtree.
Dissolved by the shape rule -- a set is part of the bank, and a
`reference.kb/` is by name not must-read. The question of where sets
live stopped being askable once a set was a directory of the bank's
own shape.
