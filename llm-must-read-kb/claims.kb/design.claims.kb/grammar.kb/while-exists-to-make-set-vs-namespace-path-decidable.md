# `while/` Exists to Make Set-vs-Namespace Path-Decidable

A directory under a point juncture is a namespace directory; a
directory under `while/` is a set. That distinction is decidable from
the path alone, and it is what `while/` buys the grammar: a program
that lists a bank needs only the prune key. The interval-vs-point
gloss ("while" holds for a span, "before" names an instant) is true
but not what the name is for.

A `when/` directory could not have served: `when/git/` would be
ambiguous between a prefix and a set.
