# The Gate Body Lives Inside the Set

The point trigger for a set's own occasion -- the body that shapes the
approach to X, read once at X's begin -- lives inside the set as
`while/X/before/ANY-<x>.md`, not beside the stub in the parent. The
stub is the gate; two parent lines for one occasion is aliasing by
another name.
