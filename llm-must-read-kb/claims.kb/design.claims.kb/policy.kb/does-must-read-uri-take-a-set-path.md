# Does `must-read://` Take a Set Path?

`must-read://DIR` resolves `DIR/must-read.kb/`. Whether it also
accepts a set path (`must-read://~#making-code-changes`, or the set's
own directory) or the listing tool is invoked on the path directly is
unsettled and cosmetic; an answer changes one line of the recognition
directive.
