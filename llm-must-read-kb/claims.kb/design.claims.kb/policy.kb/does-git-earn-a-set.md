# Does `git` Earn a Set?

`before/git/` is namespace nesting today: three `before/` files, fired
in almost every session. It would earn a set once it has an `after/`
member -- clustering across junctures is what a set buys that a prefix
cannot -- if the pull, paid nearly every session, is judged cheaper
than the split. Turns on the economics claim's pull-cost term.
