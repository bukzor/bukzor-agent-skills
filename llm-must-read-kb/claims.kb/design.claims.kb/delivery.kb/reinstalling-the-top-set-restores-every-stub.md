# Reinstalling the Top Set Restores Every Stub

After a context reset, re-listing the top set brings back every stub,
and the per-turn review re-notices any set whose occasion still holds.
So sets add no re-install burden of their own: the compaction problem
is the top set's, once. What remains per set is the noticing premise in
a post-compaction, mid-flow state.
