# `llm-must-read-ls` Is the One Instance of the Prune

The listing command lives in one named tool, `~/bin/llm-must-read-ls`,
so the prune is single-instanced and refinable in one place; host
stanzas name the tool rather than spelling the `find`. The tool's
implementation shrinks to that one line; its name is the recognition
vocabulary.
