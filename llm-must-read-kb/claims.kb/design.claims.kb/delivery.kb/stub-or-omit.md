# Stub or Omit?

Whether a listing should show unpulled sets as stubs (risking a
curious agent expanding them early) or omit them (risking an agent
that never learns they exist). Dissolved by the cost bound: early
expansion costs the eager listing and omission breaks recognition, so
there was never a trade to weigh.
