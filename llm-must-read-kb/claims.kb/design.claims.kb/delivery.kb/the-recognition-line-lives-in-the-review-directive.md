# The Recognition Line Lives in the Review Directive

The one sentence an agent needs to act on a stub -- "a `while/X/` line
is a set: when X begins, run `llm-must-read-ls` on it" -- lives in the
per-turn review directive (the trigger-installation session's draft
`when/planning-a-turn/review-installed-triggers.md`), because that body
is what the agent has open at the moment it scans a stub, and there it
carries a moment and a verb. The host context carries only the static
installers. Everything else about the grammar is in the tree.

the shape that measured 5/7.
