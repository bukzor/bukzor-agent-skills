# A Bank Is a Partition of Triggers Indexed by Occasions

`while/X/` is the set at X and the bank is the set at top; every
trigger belongs to exactly one set, the one its path names. No
operation moves a trigger between sets.

Tried and not here: a fibration (Grothendieck construction over the
occasion preorder), which needs restriction maps from the set at X to
the set at Y for Y entailing X. The design has no such operation, so
the total-space picture carried an insight -- top-set, uniform shape --
that this weaker structure keeps, and a name it does not earn.
