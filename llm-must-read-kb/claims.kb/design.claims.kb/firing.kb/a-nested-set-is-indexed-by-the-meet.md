# A Nested Set Is Indexed by the Meet

A set reachable only through `while/X/while/Y/` is the set at X meet
Y, whether or not Y entails X on its own; its members entail both.
Meet lives at sets and nowhere else -- a namespace directory under a
point juncture is a key prefix, not an occasion, so `before/git/commit`
is one occasion named "git commit", not the meet of two.
