# Every Firing Trigger Is Installed

At every moment, every trigger that fires is installed. Proof shape: T
fires at t, so T's occasion holds or is about to; by entailment X holds
or is about to; by timeliness X began by t; by the noticing premise and
the install law, X's set was listed by t; by monotonicity it is still in
context. The theorem rests on exactly one premise nobody can discharge
from the tree -- that the agent noticed X begin -- and that is the
premise every remaining question in this ledger is about.
