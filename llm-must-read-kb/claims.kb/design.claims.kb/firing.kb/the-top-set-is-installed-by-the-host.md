# The Top Set Is Installed by the Host

The set at top -- the bank itself -- is installed by the host context
(a CLAUDE.md stanza, a skill's `SKILL.md` imperative), never by a
trigger in the bank: an agent would have to read the bank to learn to
read the bank. This is the one install that is not a begin-notice, and
the one place a bank needs anything outside itself.

The three scopes of the skill -- personal, project, skill -- are each a
top set with its own host; see
`../pullers.kb/the-three-scopes-are-mechanically-pulled-sets.md`.
