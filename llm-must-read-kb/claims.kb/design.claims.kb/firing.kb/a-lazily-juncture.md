# A `lazily/` Juncture

Proposed as a home for "lazily, before first tool call" and its kin.
Dissolved: laziness is not an occasion, it is the install semantics of
a set -- listed when its occasion begins, not before. A juncture named
for a listing policy would be the one non-relational juncture in the
grammar, and everything it would hold is a set under `while/`.
