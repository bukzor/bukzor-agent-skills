# An Ended Occasion Leaves Its Set Harmlessly Installed

A trigger whose set's occasion has ended cannot fire: its own occasion
entails the set's, and the set's is false. So a set installed past its
occasion's end costs context and nothing else, and no uninstall
mechanism is needed. Intervals need not be closed.
