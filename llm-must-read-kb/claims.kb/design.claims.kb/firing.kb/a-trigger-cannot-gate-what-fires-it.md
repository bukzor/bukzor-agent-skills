# A Trigger Cannot Gate What Fires It

Whatever an agent needs in order to recognize that a trigger's occasion
holds -- vocabulary, notation, the existence of the bank -- must reach
it unconditionally. A directive filed behind a condition reaches only
agents who already know the condition exists. This is the skill's own
standing rule, cited here because the root of every bank rests on it.
