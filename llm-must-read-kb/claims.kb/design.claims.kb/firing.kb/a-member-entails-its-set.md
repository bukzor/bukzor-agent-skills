# A Member Entails Its Set

Every trigger in the set at X has an occasion that entails X. The
contrapositive is the test the bank's owner first stated: if X does
not hold, no member of X's set can fire. Smallest example:
`writing-python-code` entails `making-code-changes`;
`spawning-a-sub-agent` entails no candidate below top, so it stays in
the top set.

Stale when: a member is filed whose occasion can hold while X does not.
