# A `before/first-tool-call.md` File as the Root

Proposed twice: a trigger file inside the bank whose body installs the
bank. Dissolved by the recognition rule and the host-install claim -- an
agent cannot read a file to learn that files must be read. A
`before/first-tool-call.md` may still exist as an ordinary point
trigger for session-start chores; it does no installing.
