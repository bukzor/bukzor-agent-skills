# reference.kb -- maintenance guide

Procedures a consumer loads on demand while authoring or repairing
triggers; `SKILL.md` links each.

## What belongs here

- A method for one authoring task, one file per task.

## What does NOT belong here

- The trigger format, junctures, and naming -> `SKILL.md`.
- Rationale for a convention -> an ADR in `../../../docs/dev/adr/`.

## When to add

When authoring a trigger needs a procedure `SKILL.md` would otherwise
inline.
