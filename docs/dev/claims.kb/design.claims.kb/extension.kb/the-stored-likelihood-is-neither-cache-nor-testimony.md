# The Stored Likelihood Is Neither Cache nor Testimony

`llm-discourse-graph`'s `likelihood` is a written projection in the
unmarked middle: attribution and date are optional fields and the
skill ships no evaluator, so a reader can neither refresh the number
nor weigh it. That is evidence the format has fallen behind, and
none at all for deleting anything: the gap closes cheaply, because
git supplies the missing attribution and date -- a carried-over
value becomes lawful testimony without being rewritten.
