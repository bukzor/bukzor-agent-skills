# An Instance Ruling Graduates Only by Presentation

A ruling binds what it was asked about. It becomes standing law --
graduation, binding the next case -- only when the generalization is
itself put to the owner and ruled; nothing graduates by inference or
silence.

- The generalization is a new claim with its own warrant: the
  instance is evidence for it, never a signature on it (WARRANT).
  Filing it as ruled launders an agent's induction into the owner's
  voice.
- Force graduates the same way. A recommendation stays elective until
  the owner's word raises it -- "ah yes, the in-chat ledger
  mandatory, yes" (user, 2026-08-31) is obligation arriving, and
  nothing cheaper is.
- A partial rejection graduates as the partial thing it is; filed as
  a confirmation, it destroys the finding.
- Silence moves nothing in either direction: the record's own law
  admits no act nobody issued (EXPLICIT), and an unpresented
  generalization is exactly that.

Declined: precedent-reasoning -- "the owner accepted this here, so it
is policy" -- which spends the owner's authority on cases they were
never shown.
