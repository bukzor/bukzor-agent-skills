# The Pass Collection Is `quality-passes.kb/`

"Quality" disambiguates; "pass" says the item acts on the work. An item reads
"quality pass: one-home".

Declined: `self-audit.kb` -- "self" is false for a pass run on another's work,
and "audit" is after-the-fact only; `checks.kb` -- "check" alone has too many
meanings, and reads as passive.
