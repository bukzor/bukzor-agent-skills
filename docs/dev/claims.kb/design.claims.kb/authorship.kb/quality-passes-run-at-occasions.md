# A Quality Pass Runs at an Occasion

A **quality pass** improves work against one quality: what it improves, how to
walk the work, what a finding means, and how it is repaired. A must-read entry
names an occasion and points at the passes due then; the pass itself names no
occasion. A pass run while writing and one run after editing differ by occasion
alone.
