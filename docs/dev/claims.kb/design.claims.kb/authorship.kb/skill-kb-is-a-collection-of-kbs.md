# `skill.kb/` Is a Collection of a Skill's Runtime kbs

A skill's runtime material lives under `skill.kb/`, out of the way of the
skill root: its triggers, quality passes, procedures, and references, each a kb.
"kb" is a kind, so the directory is a homogeneous collection.
