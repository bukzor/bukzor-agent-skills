# Smoothing Is a Quality Pass

Smoothing walks a ledger's graph top-down, then bottom-up, applying the other
quality passes node by node -- each claim against its rung's question, its
premises, its siblings, and the rulings it quotes -- adjusting nodes and edges,
until a walk changes nothing.
