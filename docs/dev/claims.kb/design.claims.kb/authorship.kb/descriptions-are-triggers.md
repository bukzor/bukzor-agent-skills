# Descriptions are triggers

A description's one job is retrieval: it is read only by agents
deciding whether to load, so every token either raises the chance of
loading in a situation that needs the skill, or is waste. Write
must-load-when conditions only, in the words a user would actually
use. A what-it-does summary earns perhaps a tenth of a trigger's
value; "MUST load on /name" earns nothing at all, since named
invocation never consults the description.
