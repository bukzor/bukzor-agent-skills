# An ask's shape is fixed at the moment it is raised

An ask's shape is fixed at the moment it is raised: a gate holds the
agent's next move, a veto names a default already in force, an offer names a
further act available on request. Classifying by what happened afterward is
what let the 2026-09-03 review bin gates as post-act vetoes.
