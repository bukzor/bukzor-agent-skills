# extension -- how one skill is built on another

A skill extends another by telling the agent to read it and then
adding to what it found: a few more words in the default ontology,
no requirement how or whether they are used, auxiliary and sub-
theories encouraged. The encouragement lives in the basis skill;
an extension inherits it by not contravening it.

This theory also holds the questions about the fleet's first
extension -- the reform of `llm-discourse-graph`. The ones still
open carry `standing: open`; rule one by editing its file.
