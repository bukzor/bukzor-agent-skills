# An Unrepresentable Judgment Is Written Anyway

When a judgment has no lawful place in the format, write it down
anyway -- an extra line, prose, a duplicate field -- and let
validation fail: the failure is the tripwire firing, not an error
to appease. A tripwire sees only what was written: the
assessor-collision lint can flag a second judgment that landed in
the file, and nothing can flag the one a writer self-censored away
-- a missing field is silent about itself. Every
deferral-by-tripwire in this batch is lawful only jointly with this
rule.
