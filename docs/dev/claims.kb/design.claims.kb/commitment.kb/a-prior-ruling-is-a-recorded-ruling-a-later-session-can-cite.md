# A prior ruling is a recorded ruling a later session can cite

A prior ruling is a recorded ruling available to a later session, and
derivation from prior rulings is reading what they entail and citing the address. The
adjudication collection of 2026-09-01 was written upward from anecdotes while
its prior rulings sat on disk uncited; the rule "read what the priors already entail
and cite it" entered the claims-kb skill on 2026-09-03 in response.
