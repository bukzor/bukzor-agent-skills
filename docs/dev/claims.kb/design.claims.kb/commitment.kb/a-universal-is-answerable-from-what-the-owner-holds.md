# A universal is answerable from what the owner already holds

A universal is a commitment the owner can rule on from what they already
hold, with nothing to dereference. A particular names an instance the owner
must first go and read. The owner's ruling of 2026-08-31 -- ask about
universals, "what i'd do, what i want" -- is the instance this generalizes.
