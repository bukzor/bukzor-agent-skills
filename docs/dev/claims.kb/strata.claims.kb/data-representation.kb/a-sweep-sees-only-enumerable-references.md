# A Sweep Sees Only Enumerable References

Everything `reference` computes -- reachability, cones, taint,
weights -- runs on the edges the target can enumerate, and
enumerability is a target property, not a corpus property: the same
citation is an edge as a keyed field and invisible as a prose span.
`reference`'s own stale-when -- when enumerable edges are the
minority, every computation there runs on a sample -- is therefore a
representation condition, priced here per target. The repair is
representation-level too: promote the reference into a keyed field
the target enumerates, rather than teaching the sweep to read prose.
