# A juncture is observable when the runtime sees it, semantic when only intent marks it

A juncture is the state at which a directive must already be in effect. It
is observable when the runtime can see it as an event, such as a tool call or a
write into a directory, and semantic when only the agent's intent marks it, such as
being about to mint normative text.
