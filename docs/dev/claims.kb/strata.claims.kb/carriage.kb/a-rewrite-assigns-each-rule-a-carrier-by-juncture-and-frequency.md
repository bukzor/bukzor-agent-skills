# A rewrite assigns each rule a carrier by juncture kind and load frequency

A rewrite of the instruction layer assigns each rule a carrier by juncture
kind and load frequency: observable junctures to hooks, frequent semantic ones
to the every-session tier, rare semantic ones to a bank listing, and rationale
to the cold tier where it is read to be argued with. This is what "the
framework bears on a full rewrite of preferences, must-reads, and skills"
means operationally.
