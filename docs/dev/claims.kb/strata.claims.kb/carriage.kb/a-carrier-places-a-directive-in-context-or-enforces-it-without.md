# A carrier places a directive in context or enforces it with no context at all

A carrier is what puts a directive in an agent's context or enforces it
with no context at all. The kinds in use: unconditional text, a listed bank
whose bodies load on match, a body loaded on invocation, a brief handed to a
child, and a hook.
