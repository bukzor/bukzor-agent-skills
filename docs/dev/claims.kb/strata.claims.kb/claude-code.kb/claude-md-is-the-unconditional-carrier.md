# CLAUDE.md files are the unconditional carrier

CLAUDE.md files load at session start and are the unconditional carrier;
the must-read listing installs at the first tool call by the Required Reading
stanza; a skill body loads on invocation or description match; a brief is the
Agent tool's prompt.
