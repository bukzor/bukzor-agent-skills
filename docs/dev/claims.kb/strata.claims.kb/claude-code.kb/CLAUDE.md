# claude-code.kb -- maintenance guide

`../claude-code.md` defines this theory and stipulates its words.

## What belongs here

One claim per file about proper-noun facts about Claude Code's loading and hook behavior, disposable when the tool changes, confined to the words `../claude-code.md` and
its containers admit.

## What does NOT belong here

Any claim that would survive a change of tool: that is another theory's, and a claim needing its words imports
it through `why:`.

## When

Add a file when a claim in this vocabulary is made, contested, or ruled.
