# Why Did the Fleet Fragment?

As wrestled (`design-next.kb/`, as self-doubt): five overlapping
skills, one machine built three times -- did discipline slip?

Settled in diagnosis: no. Each v1 skill is one stratum grown into a
vertical silo, and the triplicated staleness machinery marks exactly
the stratum (`view`) that had no shared home -- the pattern indicts
the architecture, not the discipline. Residue, deliberately outside
this ledger: v2's shape. What must be preserved is the invariant and
three laws; what to build is `design-next.kb/`'s to decide.
