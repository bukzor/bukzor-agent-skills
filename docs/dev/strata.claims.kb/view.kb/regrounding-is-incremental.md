# Re-Grounding Is Incremental

A reader's held context is itself a view of the corpus, and it
refreshes the way any view does: by a derivative. Folding a small
diff into a theory already held is cheap; evaluating a whole
alternate that differs slightly is not -- the reader cannot see
where the differences are. This is a load-bearing reason the word is
kept in diffable form: the diff is the derivative of understanding,
and time-travel is what makes it computable.
