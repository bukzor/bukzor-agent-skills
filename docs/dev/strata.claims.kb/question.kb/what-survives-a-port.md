# What Survives a Port?

As wrestled (ACS's reason to exist): when the system is rebuilt on a
new substrate, what carries over with certainty, and what is at risk?

Settled, thrice measured: everything stated at theory level carries
-- a port is the same theories reinterpreted -- and what varies is
the enforcement grade each law lands at. Markdown kbs, PRMS, and now
Python modules; zero theory-level casualties, as ACS predicted.
