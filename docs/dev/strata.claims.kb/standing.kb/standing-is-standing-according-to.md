# Standing Is Standing-According-To

Standing is a two-place function: of the evidence, and of a stance
-- which evidence and rulings a reader admits, whose verdicts they
trust. Each stance induces its own fixpoint; consensus is agreement
across stances, a computable observation, not a property of the
store. At unbounded scale this stops being optional: there is no
global arbiter even in principle, so a one-place "the standing" of
an entry is a category error the schema must not encode.
