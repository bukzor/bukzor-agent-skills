# Force Is Computed, Never Asserted

A claim states; an effective act counts. Which acts count -- the
effective set every fixpoint reads -- is computed per stance, and
no claim can carry it: "this act is effective" as an assertion is
the category error STANCE names for a one-place standing, one level
down.

Force is the one non-propositional ingredient the deflation leaves:
claims all the way down, plus exactly one law about what counts.
The declined alternative -- effectiveness stored as a mark on the
act or on the claim it judges -- is standing stored as ground
truth, the condition that voids this theory's stamp.
