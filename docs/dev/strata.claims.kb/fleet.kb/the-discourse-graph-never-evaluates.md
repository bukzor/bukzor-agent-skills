# The Discourse Graph Never Evaluates

`llm-discourse-graph` holds the standing stratum's carrier and stops
there: judgments accumulate and no operator ever runs, so the graph
stores evidence but never computes standing. In the unified claim
scheme that is lawful -- assessor-keyed judgments are testimony,
each assessor's act at a date, and the system merely has no
verdicts, only a pile of them. What v1 ships is not: its likelihood
is a scalar whose attribution and date are both optional, so it is
neither stamped-and-regenerable nor attributed-and-dated --
TESTIMONY's unmarked middle -- and with no view function TRIANGLE
cannot be stated of it at all. A lawless cache, one grade below a
stale one. So CONTINUUM's porting note understates twice: moving to
the mechanized side is acquiring an evaluator for the first time,
and v1's stored numbers are not answers to port. The lawless middle
is an omission, not a wrong: supplying attribution and a date lands
them in the testimony branch, which is the reachable one -- the
cache branch needs the evaluator that was never written.
