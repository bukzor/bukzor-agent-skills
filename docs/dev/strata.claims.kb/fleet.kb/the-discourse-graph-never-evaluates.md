# The Discourse Graph Never Evaluates

`llm-discourse-graph` holds the standing stratum's carrier at
continuous resolution and stops there: assessor-keyed judgments
accumulate and no operator ever runs, so the graph stores evidence
but never computes standing. That is lawful -- its judgments are
testimony, each assessor's act at a date -- but it means the system
has no verdicts, only a pile of them. So the porting note in
CONTINUUM understates: moving to the mechanized side is not only
choosing a quotient, it is acquiring an evaluator for the first
time, and the choices the operator forces (threshold, join, defeat
calculus) have no answers recorded in the graph to port.
