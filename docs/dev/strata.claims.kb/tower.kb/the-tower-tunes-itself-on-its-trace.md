# The Tower Tunes Itself on Its Trace

Meta-reasoning takes the system's own history as input: which
rulings were made and unmade, which formulations survived contact,
which retractions propagated. Tuning the tower -- and the tower over
it -- requires that trace, so the ledger's own word is the corpus of
the next level up. A system that kept only its current state could
be operated but not improved.
