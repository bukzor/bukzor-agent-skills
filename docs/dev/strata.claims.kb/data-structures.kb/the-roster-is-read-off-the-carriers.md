# The Roster Is Read Off the Carriers

Six generic structures, closed under nesting, present every carrier a
central theory quantifies over: **atom** (a scalar or a key),
**record** (fixed fields), **map** (keyed by key), **sequence**,
**set**, and **reference** (an atom whose value is another entry's
key). Read off: the word is a sequence of update records and state a
map of payloads (`history`); a schema is a record of sorts and a
collection a map of instances (`record`); the edge set is a set of
key pairs (`reference`); an evidence row is a record with a
set-valued premises field, a status an atom fibered by a certificate
record (`standing`); a stamped value is a value-stamp record
(`view`); a bank is a set of trigger-act rules (`protocol`); a theory
definition is a record with sequence-valued fields (`genre`).

The roster is inventory, not legislation: it is derived by inspecting
the theories above it, so a new carrier there widens it, never the
reverse -- which is why nothing below cites this file.
