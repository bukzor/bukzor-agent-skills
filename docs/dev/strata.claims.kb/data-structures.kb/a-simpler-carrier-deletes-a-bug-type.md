# A Simpler Carrier Deletes a Bug Type

Choosing a carrier is a modeling act, and collapsing its structure
deletes the class of bug that structure carried -- silently, since
the simpler carrier has no place to express it. The worked instance
is COMPLETION's: flatten the fibered status order to a plain
enumeration and two rival certificates become one value with two
histories -- the conflict the join-failure was built to crash on can
no longer be stated, let alone caught. Prefer the carrier that keeps
the bug expressible over the one that is easier to store; the store's
convenience is `data-representation`'s problem, not a license to
shrink the carrier.
