# Order Lands Only Where the Target Realizes It

The word's order is content, so every target must say which of its
native orders carries it: memory by position, datalog by an explicit
rank attribute -- order as data -- and the filesystem by nothing but
name collation. That last makes zero-padded numeric prefixes a
contract, not a style choice: unpadded, entry 10 collates before
entry 2, and the fold silently permutes the word it was supposed to
replay. A target with no declared realization has not stored the
history; it has stored a set that used to be one.
