# A Tool Never Hard-Fails on a Judgment Call

Where the check is really a judgment -- vocabulary confinement
beyond label references, contradiction, tension, staleness --
enforcement is advisory or absent, never a hard failure: a tool
that blocks on judgment pretends to a judge's seat it cannot hold.
Mechanical facts -- label uniqueness, dangling references, cycles,
grammar -- may fail hard.
