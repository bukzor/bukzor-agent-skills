# Instances cite the skill

The reference arrow points one way: a worked instance names the skill
that produced it (`depends:`, provenance notes); a skill names no
instance. A skill that cites its exemplars hands the answer to
exactly the agent who must not see it -- any blind exercise whose
answer is that instance -- and couples stable skill text to an
unbounded, churning list. `grep` finds instances by their citations;
nothing finds a leaked exemplar before it burns a study. Material
inside the skill's own directory is part of the skill, not an
instance, and may be referenced freely.
