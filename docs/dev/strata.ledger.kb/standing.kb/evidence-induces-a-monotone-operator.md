# Evidence Induces a Monotone Operator

The evidence set -- warrants, certificates, verdicts, recorded fiats
-- determines an operator on status-assignments over the entries,
raising each entry as far as the evidence citing it (through the
reference structure) supports. Its rule format is the law: ascent
steps require a certificate premise; descent enters only as a
recorded fiat or as removal of evidence, never as a rule's
conclusion. So long as defeat is absent, the operator is monotone.
