# Enforcement Grade Is Who Computes the Product

One bank, many interpreters: the same rules can be held by operator
attention, by tooling that checks after the fact, or by a kernel that
makes violation inexpressible. The *grade* of enforcement is which
machine computes the synchronized product -- a property of the
interpretation, not of the bank. Porting a bank across runtimes is
choosing a new interpreter; the adapter boundary is exactly the set
of these interpretation maps.
