# Every Boundary Is a Seam

Each stratum computes its structure treating the strata below as
frozen input -- a stratified definition: fixpoints below are
parameters above, never revised from above. The freeze loses nothing:
triangular operators restrict
(`../fixpoint.kb/triangular-operators-restrict.md`), so the floor
solved alone equals the floor inside the whole. The familiar seam
between what is monotonic and what revises freely is not one special
boundary; it recurs at every floor of the tower, and locating a
design question is largely naming which seam it sits on.
