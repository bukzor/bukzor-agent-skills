# One Structure, Twice

The conservative-extension poset with a locality condition appears
twice: once as the genre system the tower hosts, once as the tower
itself. That is why self-application keeps succeeding in this
ecosystem -- the system is a model of its own organizing principle,
so turning it on itself creates no new obligations, only new
instances.
