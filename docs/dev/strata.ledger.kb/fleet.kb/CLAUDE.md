# fleet.kb -- maintenance guide

The proper-noun theory, last and throwaway: where the named systems
sit in the tower. Every other theory stays abstract so that changes
to these systems land only here.

- `prior:` tower
- `ontology:` the named systems -- the llm-* skills of this repo,
  `design-next.kb/`, PRMS
  (`prototype.personal-reasoning-management`), ACS
  (`ideation.epistemics`), llm-stet (`prototype.llm-stet`), and their
  internal names (GENERIC_BASE, LEAST_FIX, port vector, ...)
- `defeated by:` any named system changing

## What belongs here

A correspondence: this system's concept realizes (or contradicts)
that tower claim. One claim per correspondence cluster.

## What does NOT belong here

Anything that would still be true if every named system were deleted
-- state it upstream and cite it from here.
