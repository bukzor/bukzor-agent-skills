# Names are verbs or systems

A skill's name is its earliest retrieval surface -- `ls` is
discovery, and the name is scanned before any description. Two
grammars survive that scan: a verb phrase, commanding the
transformation (`formalize`, `list-open-questions`), or a system
name, owning a domain (`incident-forensics`, `walled-web`). A name
that is neither -- a bare object, an in-joke -- makes every reader
reconstruct what command is meant, on every scan.
