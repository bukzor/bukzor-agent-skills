# Delete-When Clauses

Durable artifacts can name their own retirement condition — session
entries carry "Delete When" headings today. The clause is a wake
condition: when true, the artifact is due disposition — not
automatically gone.

Today: prose headings nothing reads; expired entries accumulate, and
a store that accumulates unread writes teaches readers to stop
trusting reads.

Satisficed when: a retirement condition is recordable in the wake
grammar and its firing surfaces the artifact for disposition, while
execution stays with the agent or operator — surfacing never
deletes.
