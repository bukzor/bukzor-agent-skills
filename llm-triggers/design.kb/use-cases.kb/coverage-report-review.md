# Coverage-Report Review

Interpretation-not-compilation replaces staleness checks with a
coverage report: which action-shaped triggers are mechanically bound
on this system versus floor-only. A report nobody reads is a fired
trigger nobody notices, one level up.

Today: the report is designed
(`../040-design.kb/interpretation-not-compilation.md`); no juncture
consumes it.

Satisficed when: reviewing coverage is itself a recorded recurring
condition — the subsystem's own read-backs swept by the same
machinery they implement.
