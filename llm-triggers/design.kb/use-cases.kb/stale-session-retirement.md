# Stale Session and Project Retirement

Session entries (the global task scope) and project backlogs go
quiet without being dispositioned: the work fizzled, moved, or
finished un-filed. Entries name a "Delete When" nothing evaluates
(`delete-when.md`), and "no progress for N weeks" is recorded
nowhere as a condition at all.

Today: manual audits during occasional backlog sweeps.

Satisficed when: an instance can record "surface entries with no
progress in \<threshold\>" as a wake condition — threshold per
instance, progress defined over observable state (e.g. the entry's
git history) — so quiet entries get surfaced for retire/keep
judgment instead of accumulating as landfill.
