# Use Cases — wake-shaped attention

One file per concrete situation where something recorded must later
claim attention without an agent spontaneously deciding to look.
These are validation targets: the wake-condition grammar
(`../040-design.kb/trigger-desc.md`), the sweep, and their schemas
must satisfice every entry here — each worked through with a
concrete answer during schema design, before implementation.

## What Belongs Here

- One use case per file: the need, what serves it today, and what
  "satisficed" means — stated as effects, not mechanisms
- Implementation sketches only when clearly marked non-normative

## What Does NOT Belong Here

- Requirements — `design-next.kb/030-requirements.kb/` and this
  tower's `040-design.kb/` own those
- Solutions — a worked design graduates into a `040-design.kb/`
  entry that cites the use cases it serves

## When to Add / Read

- **Add** when discussion surfaces a wake-shaped need not reducible
  to an existing entry.
- **Read** when designing or reviewing the wake grammar, the sweep,
  or their schemas: work through every entry and check the design
  gives each a concrete answer.
