# Deferred Task Wakes

A task deferred `at:` a date or `after:` an event must return to
nag-eligibility exactly when its condition holds — the contract that
justified removing horizon buckets from the working set (design-next's
task class). Deferral is only cheap if wake is reliable: if waking
depends on luck, agents rationally stop deferring and the working set
bloats back into a bucket pile.

Today: the grammar exists (`../040-design.kb/task-deferral.md`,
proposal); nothing evaluates it.

Satisficed when: deferral descs are evaluated per task-deferral's
cell contracts, and a task whose condition holds cannot stay
suppressed past the next named juncture.
