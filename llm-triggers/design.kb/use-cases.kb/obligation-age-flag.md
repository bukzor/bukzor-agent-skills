# Obligation Age

An obligation untouched for months is mis-ranked, secretly blocked,
or dead — every one a disposition worth prompting. Age is observable
for free (git history); whether age alone warrants surfacing, and at
what threshold, plausibly differs per instance.

Today: old lines sit; backlog sweeps see existence, not age.

Satisficed when: an instance that wants age-flagging can record it
("surface obligations untouched for \<threshold\>") and one that
doesn't records nothing — the system carries no default opinion
either way.
